# CCF 四川大学学生分会官网

这是 CCF 四川大学学生分会的新版宣传网站。当前版本已完成信息架构、双语内容、响应式页面、交互视觉和现有分会资料接入。

## 本地预览

页面没有第三方依赖，可以直接打开 `index.html`。也可以在当前目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 当前包含

- 中英文切换
- 响应式桌面端和移动端导航
- 关于、活动、成就、开源、加入模块
- 首页“知识共振场”：鼠标、触摸、滚动或方向键都会自动扰动整张弹性织网，让波纹持续传播并显影 SCU CCF
- 活动区“可能性切片仪”：在唯一一处保留四层卡片动画，用于切换学术引领、竞赛训练、学业帮扶与生涯发展
- 可切换的活动切片与成果档案
- 连续式分会理念展示与沉浸式最终加入入口
- QQ 群弹窗（迎新群：1033172661）与二维码位置预留
- 在线报名表单及后端接口预留
- 官方 GitHub 仓库入口
- 从现有分会官网整理的活动照片、品牌项目、竞赛成绩与集体荣誉
- 减少动态效果的无障碍适配

## 后续接入

在 `script.js` 顶部的 `SITE_CONFIG` 中继续补充：

- `qqGroupUrl`：一键加群链接（可选）
- `registrationEndpoint`：报名表单提交接口

群二维码、在线报名后端和不适合从公开网页推断的成员资料仍保持空缺，待分会确认后接入。
