# SCU CCF web fonts

The website self-hosts compact subsets derived from Noto Sans SC and
Noto Serif SC. Only characters used by `index.html` and `script.js` are
included so the page does not need to download the full CJK font files.

- `scuccf-sans-sc.woff`: variable-weight interface and display sans
- `scuccf-serif-sc.woff`: variable-weight editorial accent serif
- `OFL.txt`: SIL Open Font License 1.1

The CSS family aliases are intentionally changed to `SCU CCF Sans` and
`SCU CCF Serif`.
